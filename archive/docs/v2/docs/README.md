# Documentation map

This folder is published as the GitHub Pages site.

- `index.html` — documentation home
- `users/` — quick start and reading responses
- `learners/` — TDL vocabulary and request lifecycle
- `developers/` — request contract and checked-in HTTP examples
- `advanced/` — parent context, TDL Walk vs JavaScript flattening, and detailed flattening walkthrough
- `examples/` — index of relevant checked-in requests
- `reference/` — attributes, response shapes, glossary, troubleshooting
- `assets/site.css` — shared lightweight styling

The site uses relative links so it works under the repository's GitHub Pages project path. Examples distinguish observed behavior from illustrative JSON shapes.
