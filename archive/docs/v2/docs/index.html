Start with the purpose

This documentation explains how this project communicates with Tally, how TDL describes the data to retrieve, and how nested data such as voucher ledger entries can be flattened into useful rows.

The goal is to build shared understanding first, then make the JavaScript API declarative and easy to use.

Examples

The central example: Receipt vouchers

We use Receipt vouchers because they make the relationship easy to see: a voucher is the parent object, and AllLedgerEntries contains child ledger-entry objects. Our working collection traverses those entries and exposes parent voucher number and date on each resulting row.

Documentation principle: examples are labelled as tested, illustrative, or conceptual. An illustrative JSON shape is not presented as a literal Tally response.
