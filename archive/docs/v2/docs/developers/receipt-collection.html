Example: a small Receipt collection

Start with a single collection and only the fields needed by the caller.

Checked-in example This example follows http/asJson/receipt/small.http.

POST http://localhost:9000
Content-Type: application/json
version: 1
tallyrequest: Export
type: Collection
id: KSReceiptLegacyJsonTest

{
  "static_variables": [
    {"name": "svExportFormat", "value": "json"},
    {"name": "svCurrentCompany", "value": "mani9"}
  ],
  "tdlmessage": [
    {
      "definitions": [
        {
          "metadata": {
            "name": "KSReceiptLegacyJsonTest",
            "type": "Collection",
            "ismodify": false
          },
          "attributes": [
            {"Type": "Vouchers:VoucherType"},
            {"ChildOf": "$$VchTypeReceipt"},
            {"Fetch": "Date"},
            {"Fetch": "VoucherNumber"},
            {"Fetch": "PartyLedgerName"},
            {"Fetch": "Amount"}
          ]
        }
      ]
    }
  ]
}

What this demonstrates

  • Type selects the voucher object collection.
  • ChildOf narrows the source to Receipt vouchers.
  • Fetch lists the methods required by the caller.
This is the repository's JSON output example. The compact report example described in the project history uses a separate TDL Report definition and JSONEx output. Do not assume their response structures are identical.
