Headers

HeaderRole in the examples
Content-TypeDeclares a JSON request body.
versionRequest protocol version used by this setup.
tallyrequestChooses an operation such as Export or Import.
typeChooses the export target kind, such as Collection or Data.
idNames the collection/report/data target requested.

Static variables

"static_variables": [
  {"name": "svExportFormat", "value": "jsonex"},
  {"name": "svCurrentCompany", "value": "mani9"}
]

These values are environment-specific. They are not the collection definition itself.

TDL definitions

A custom collection definition is supplied in the tdlmessage structure. In the checked-in example, each definition contains metadata and attributes. A source collection can be defined separately and referenced by the collection that walks it.

Keep concerns separate

  • HTTP headers: operation envelope.
  • Static variables: runtime settings.
  • TDL: retrieval and traversal rules.
  • Response JSON: serialized result.
  • JavaScript: post-processing and application contract.
