Troubleshooting: when fields are missing

A disciplined checklist for investigating TDL collection output.

Home Users Learners Developers Advanced Examples Reference
Documentation home / Reference

A field is absent from JSON

  1. Confirm the field exists on the object context being traversed.
  2. Confirm it is included by the appropriate Fetch or Source Fetch.
  3. Check whether the value is defined on the parent or child object.
  4. Check whether the computed expression is evaluated in the intended context.
  5. Inspect the actual response, not only the HTTP status.

Parent values are missing or wrong

Do not assume that a loop-object helper refers to the parent in every collection configuration. Confirm the source collection, walk path, and source methods. The checked-in successful experiment uses Source Fetch: Date,VoucherNumber and computes from $VoucherNumber and $Date.

Response is unexpectedly large

  • Fetch only the methods required by the use case.
  • Avoid fetching nested lists unless they are needed.
  • Compare like with like: same company, date range, output format, and size measurement.

Report and collection results differ

Confirm the requested type, target id, and TDL definition. A report uses a report-oriented structure; a collection export uses collection definitions.

Best debugging rule: change one thing at a time and keep the last known working request unchanged as a baseline.
