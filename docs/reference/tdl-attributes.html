TDL attributes used in these examples

A practical, intentionally concise reference for the attributes visible in this repository.

Documentation home / Reference
AttributePurpose in the exampleReminder
TypeSelects the type of objects in a collection.Example: Vouchers:VoucherType.
ChildOfRestricts a collection to children of a specified object/type.Example: $$VchTypeReceipt.
FetchRequests methods to be included in the collection output.Use the exact methods required.
Source CollectionIdentifies the source collection used by another collection.The referenced source definition must be present or otherwise available.
WalkTraverses a nested collection for each source object.Example: AllLedgerEntries.
Source FetchRequests source-object methods for the walk context.Used here for voucher Date and VoucherNumber.
ComputeDefines a computed method using an expression.Example: ParentVoucherNumber: $VoucherNumber.
This page is an explanatory reference based on the checked-in examples. For exact formal syntax, edge cases, and release-specific support, consult Tally's official TDL documentation.
