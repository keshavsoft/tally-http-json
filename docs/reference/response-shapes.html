Collection export

A collection export returns records according to the collection definition. The exact top-level envelope and field representation depend on the chosen output format.

JSON versus JSONEx

The repository contains examples that set svExportFormat to json and others that use jsonex. In the observed JSONEx response, a field can be represented as an object containing a type and a value.

"voucherNumber": {
  "type": "String",
  "value": "471"
}

Report export

The compact receipt report uses TDL Report, Form, Part, Line, and Field definitions to control a report-oriented output. Its JSON shape differs from a raw collection export.

Do not treat a report definition and a collection definition as interchangeable just because both can return JSON. Choose based on whether the task needs a report layout or a collection of objects.
