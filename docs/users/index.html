What does this project help with?

It demonstrates ways to request data from a running Tally instance over HTTP, receive XML or JSON-shaped data, and make that data easier for an application to consume.

What you need

  • A running Tally instance with its HTTP interface enabled.
  • Access to the company you want to query.
  • A client that can send HTTP requests, such as the VS Code REST Client used in the examples.
  • Knowledge of which data you want: vouchers, ledgers, stock items, or reports.
