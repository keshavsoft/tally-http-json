Quick start: one request, one response

The minimum mental model for using an existing HTTP request example.

1. Open an example request

For example, open http/asJson/receipt/small.http in the repository. It requests Receipt vouchers and asks for Date, VoucherNumber, PartyLedgerName, and Amount.

2. Read the HTTP envelope

POST http://localhost:9000
Content-Type: application/json
version: 1
tallyrequest: Export
type: Collection
id: KSReceiptLegacyJsonTest

3. Read the JSON body

The static_variables set the output format and current company. The tdlmessage contains the TDL definition for the collection.

4. Inspect the result

Confirm that the response has the records and fields expected. Do not assume that a successful HTTP response means every desired field was exported: inspect the body.

The example uses svExportFormat: json. Other working requests use jsonex. Treat these as distinct output formats, not interchangeable labels.
