Reading Tally responses

How to inspect the response without confusing the transport, record, and field layers.

Look at the layers separately

  1. HTTP result: did the request reach Tally and return a response?
  2. Export status: does the response indicate success or an error?
  3. Record structure: is the result a collection of objects, a report shape, or a nested hierarchy?
  4. Field values: are the expected values present and plausible?

JSONEx field wrappers

In the demonstrated JSONEx collection response, fields may appear as typed objects, for example:

"amount": {
  "type": "Amount",
  "value": "-100.00"
}

This wrapper communicates a field type as well as its value. Do not mistake the wrapper object itself for the amount string.

Large response sizes

Full voucher exports can contain many fields and nested lists. If the task needs only a few columns, prefer a collection or report that fetches only those fields. Compare response sizes using the same measurement method.
