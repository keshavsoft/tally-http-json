TDL in plain language

TDL stands for Tally Definition Language. In this project, the important idea is that TDL definitions tell Tally what kind of records to collect and which methods or nested collections to expose.

Core vocabulary

TermSimple meaningExample in this project
ObjectA business record or structured object.A Receipt voucher or a Ledger Entry.
CollectionA set of objects that Tally can retrieve or iterate over.A collection of Receipt vouchers.
MethodA named value available on an object.Date, VoucherNumber, Amount.
FetchAsk the collection to include named methods.Fetch: LedgerName.
WalkTraverse a nested collection from each source object.Walk: AllLedgerEntries.
ComputeDefine a new method whose value is calculated from an expression.ParentVoucherNumber: $VoucherNumber.
These short explanations are an introductory mental model. For exact syntax and version-specific behavior, use the official TDL documentation and test the definition against the Tally version in use.
