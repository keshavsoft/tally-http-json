Request lifecycle: from HTTP to JSON

Follow the request in the same order Tally receives and processes it.

Home Users Learners Developers Advanced Examples Reference
Documentation home / Learners
  1. HTTP request: send a POST to the Tally HTTP endpoint.
  2. Request headers: select the operation, export type, and requested identifier.
  3. Static variables: set values such as export format and current company.
  4. TDL definitions: define a collection or report when the request needs a custom data shape.
  5. Collection evaluation: Tally selects objects, fetches methods, and may walk nested collections.
  6. Serialization: Tally returns the result in the selected output format.
  7. Application processing: JavaScript or another caller validates and transforms the response.

Envelope example

POST http://localhost:9000
Content-Type: application/json
version: 1
tallyrequest: Export
type: Collection
id: KSReceiptLedgerEntryProbe

The request header and body have different jobs. The headers identify the operation. The JSON body supplies settings and definitions used by that operation.
